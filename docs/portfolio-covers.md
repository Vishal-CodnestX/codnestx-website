# Portfolio cover artwork

Seven illustrative industry covers were generated with the built-in ImageGen tool and saved as optimized WebP assets in `public/images/clients/`. The existing jewelry, residential and logistics covers are reused. Project names and performance outcomes come from `CODNESTX_PORTFOLIO` in `src/data/codnestxData.js`.

## Shared prompt

Photorealistic premium business portfolio cover photograph, panoramic 3:1 composition, corporate editorial photography, realistic details, refined lighting, darker quiet left quarter for a white brand overlay, main subject center and right, crop-safe top right for a category badge. Edge-to-edge photo, no borders, collages, logos, letters, text or watermarks. Navy and blue software agency theme.
